HTML Data-Attribute API

No JavaScript needed — just add data-yo-* attributes and include the script tag. The SDK auto-scans the page on load.

Inline Widget

<div data-yo-widget="2:youropinion:d403xxd5j/mfks"
     data-yo-language="en"
     data-yo-auto-grow
     data-yo-auto-shrink></div>

Dialog Trigger

<button data-yo-dialog="2:youropinion:d403xxd5j/mfks"
        data-yo-size="70"
        data-yo-language="en"
        data-yo-auto-close
        data-yo-auto-grow>Open Dialog</button>

Drawer Trigger

<button data-yo-drawer="2:youropinion:d403xxd5j/mfks"
        data-yo-position="right"
        data-yo-language="en"
        data-yo-auto-close>Open Drawer</button>

Popover Trigger

<button data-yo-popover="2:youropinion:d403xxd5j/mfks"
        data-yo-position="bottom-right"
        data-yo-language="en"
        data-yo-auto-close>Open Popover</button>

Feedback Tab (Button + Drawer)

<div data-yo-feedback-tab="2:youropinion:d403xxd5j/mfks"
     data-yo-button-text="Feedback"
     data-yo-button-color="#003366"
     data-yo-position="right"></div>
