Widget (Inline Embed)

Renders the survey directly inside a container on the page — no overlay or modal. Height auto-adjusts as the user navigates between questions.

Code

const widget = yo.createWidget('2:youropinion:d403xxd5j/mfks', {
  container: document.getElementById('survey-container'),
  width: '100%',
  language: 'en',
  autoGrow: true,
  autoShrink: true,
});
