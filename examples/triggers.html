Triggers

Triggers let you auto-open surveys based on user behavior — scroll depth, time on page, exit intent, or immediately on load. Scroll down to see them fire.

Active triggers on this page

  • Time: Dialog opens after 10 seconds
  • Scroll: Drawer opens at 50% scroll depth
  • Exit intent: Popover opens when mouse moves to top of page
// Time trigger — open a dialog after 10s
const dialog = yo.createDialog('2:youropinion:d403xxd5j/mfks', {
  language: 'en',
  autoGrow: true,
  autoClose: true,
});
dialog.addTrigger({ type: 'time', delay: 10000 });

// Scroll trigger — open a drawer at 50%
const drawer = yo.createDrawer('2:youropinion:d403xxd5j/mfks', {
  position: 'right',
  language: 'en',
  autoClose: true,
});
drawer.addTrigger({ type: 'scroll', threshold: 50 });

// Exit intent — open a popover
const popover = yo.createPopover('2:youropinion:d403xxd5j/mfks', {
  position: 'bottom-left',
  language: 'en',
  autoClose: true,
});
popover.addTrigger({ type: 'exit', sensitivity: 20 });
