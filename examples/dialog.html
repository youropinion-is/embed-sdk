Dialog

Opens a centered modal overlay that dims the page and traps focus. Best for post-action surveys, onboarding flows, and NPS prompts.

Code

const dialog = yo.createDialog('2:youropinion:d403xxd5j/mfks', {
  size: 70,
  width: 600,
  language: 'en',
  autoGrow: true,
  autoClose: true,
});

document.querySelector('#open-btn').onclick = () => dialog.open();
