Drawer

Slides a panel in from the left or right edge. The page stays visible behind it — great for contextual feedback and help desk surveys.

Code

const drawer = yo.createDrawer('2:youropinion:d403xxd5j/mfks', {
  position: 'right',
  width: '450px',
  language: 'en',
  autoClose: true,
});

document.querySelector('#open-right').onclick = () => drawer.open();
