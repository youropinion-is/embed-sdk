Popover

A small panel anchored to a corner of the viewport. Floats above the page without blocking interaction — perfect for passive feedback collection.

Code

// Basic popover
const popover = yo.createPopover('2:youropinion:d403xxd5j/mfks', {
  position: 'bottom-right',
});

// Popover + floating action button
const popoverFab = yo.createPopover('2:youropinion:d403xxd5j/mfks', {
  position: 'bottom-right',
});
yo.createButton(popoverFab, {
  position: 'bottom-right',
  text: 'Feedback',
  color: '#059669',
});
